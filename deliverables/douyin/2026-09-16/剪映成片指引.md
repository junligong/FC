## 二、剪映操作（4 步）

### 1. 新建草稿并导入画面

- 剪映**首页**点左上角的 **「开始创作」** → 进入编辑界面
- 导入 `fc27-daily-2026-09-16-silent.mp4`（拖进主轨 / 或点「导入」再拖到轨道）
- 比例选 **9:16**（视频本身是 1080×1920，通常会自动匹配）
- 时间轴总长 37.8 秒，共 8 个信息段（每段一张卡片式画面）

### 2. 导入字幕（为了生成配音，不是为了显示字幕）

⚠️ **这一步必须先进编辑器**：首页（「开始创作」那个界面）里没有这些菜单，**要把视频拖进时间轴、进入编辑界面**，顶部才会出现工具栏（媒体 / 音频 / 文本 / 贴纸 / 特效 / 转场 …）。

**主路径**：编辑界面 → 顶部 **「文本」** → 面板里的 **「本地字幕」** → 选择 `fc27-daily-2026-09-16.srt`
（新版剪映常把入口收在「智能字幕」分组里，与「识别字幕」「识别歌词」并列；认「本地字幕」四个字即可）

**找不到就按顺序试这几个备选**：

1. 左上角菜单 **「文件」→「导入」→「本地字幕 / 字幕文件」**
2. 把 `.srt` 文件从访达**直接拖进**剪映编辑器窗口
3. **兜底（一定能成）**：手动逐条建文本 —— 打开 `口播稿.txt`，点「新建文本」→ 粘贴第 1 条 → 重复 8 次，文本轨右键「朗读」一样能生成配音

> 字幕时段我已经按 **AI 配音约 4 字/秒** 预留好，每条文本都比所在段落短一点，留了起声 0.3s、收声 0.1s 的呼吸，所以生成配音后不会顶到下一段——这是你说的"突兀"最直接的解法。

### 3. 生成 AI 配音

- 全选文本轨 → 右键 → **「朗读」**（有的版本在右侧属性面板里）
- 选音色：资讯速报类建议挑 **「解说 / 资讯 / 知性」** 属性的男声或女声
  （音色库随版本更新，名称以你剪映里的为准，**务必试听**）
- 语速保持默认；若某条配音明显长于画面，把该条语速提到 **1.1x**
- ⚠️ 试听重点：**「布阿迪」「C 罗」「四百七十三张」** 是否读对

### 4. 隐藏字幕轨 + 配乐 + 导出

- **隐藏字幕**：画面里已经烧录了设计好的大字，字幕叠加会重复 → 点文本轨的「眼睛」图标关闭显示
  ⚠️ 建议**只隐藏不要删除**：删轨可能连带删掉已生成的配音
- **配乐**：音频 → 音乐，搜「科技 / 电子 / 资讯 / 快节奏」类 BGM，把 BGM 音量压到 **20%–30%**，人声保持 100%
  （或直接导入 `-bgm-only.mp4` 的音轨当垫乐）
- **导出**：
  - 分辨率 **1080P** —— 与素材原生分辨率一致最清晰；选 2K/4K 属于放大插值，不会更清晰
  - 帧率 30fps，码率选「推荐」或「更高」，格式 MP4 / H.264

## 四、几个已知情况（避免踩坑）

1. **画面里已经有中文大字**，所以 SRT 只作配音源；成片里不需要额外字幕。若你想让字幕也显示，建议放在画面**最底部**并调小字号，别压住卡片文字。
2. **素材是 1080×1920**。要真正的 4K 成片需要 4K 素材，目前的画面是 1080 原生渲染——需要的话我可以重渲一版 2160×3840（约 2 分钟）。
3. **不要给这个视频加片头**：第 1 段本身就是钩子（"2 天"大数字），加片头会稀释前 3 秒。
4. 文案里的发布日期、数字口径都来自当日 5 个栏目的产物，逐条溯源在 `发布文案.md` 第四节；"开服前价格非成交价"这类口径别删，是项目硬要求。
